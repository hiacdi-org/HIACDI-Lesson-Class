# **Common design requirements for all four students**

Each student must:

1. Create a separate project folder.
2. Create `index.html` and `style.css`.
3. Use HTML for the form structure.
4. Use CSS for professional styling.
5. Use a consistent colour scheme.
6. Organize questions into clearly labelled sections.
7. Include appropriate spacing, borders, and rounded input fields.
8. Make the form responsive on mobile phones and computers.
9. Include working submit and reset buttons (submission processing is not required).
10. Ensure every input has a clear label.

## **Marking Scheme**
